Tech

A single static index.html file with no build step.

HTML, CSS and vanilla JavaScript
GSAP and ScrollTrigger for animations
Matter.js for the toolbox physics
Fonts (Unbounded, Manrope) and images are embedded in the file

Libraries load from the cdnjs CDN, so the page needs an internet connection to animate. It respects the "reduce motion" setting on visitors' devices.

Run locally

Open index.html in any browser. No install needed.

Deploy

Hosted on Vercel from this repository. Any push to the main branch redeploys the site automatically.

To update the site, replace index.html with the new version and commit.
